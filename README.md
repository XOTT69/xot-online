# XOT Online — ХОТ для Lampa

Плагін Lampa з кнопкою **ХОТ** і меню зовнішніх джерел через Online MOD.

## Джерела у меню

- Filmix
- HDRezka
- Kodik
- CDNVideoHub
- AniLibria

Ці джерела використовують **сторонній Online MOD** (із дозволу користувача); це не незалежні парсери. Їхні доступність і якість залежать від сервісу, мережі та умов акаунта. Власний серверний реєстр наразі порожній.

**Internet Archive повністю вилучено** з меню, Worker API та тестів за запитом користувача. `/api/health` має повертати `provider_count: 0` — це очікувано, бо він показує тільки незалежні серверні провайдери.

## Встановлення

```
https://xot-online.ai-beta69690.workers.dev/m.js
```

Якщо Cloudflare підключений до GitHub, після нового коміту перевір успішність збірки. Перезапусти Lampa для завантаження змін.

## Safari

Плагін встановлює темний `meta[name=theme-color]` (`#171717`) для браузерної панелі. На деяких версіях iOS Safari колір панелі визначається оформленням базового сайту Lampa або системними налаштуваннями. Плагін не перевизначає глобальний фон Lampa, щоб не зламати інтерфейс; тому темний колір Safari не гарантується.

## API

- `GET /api/health` — стан Worker.
- `GET /api/providers` — незалежні серверні адаптери (поки порожній список).
- `GET /api/search` — інфраструктурний маршрут для майбутніх API.

## Власний Kodik search API

Адаптер Kodik підключається **лише** після додавання секрету Worker `KODIK_TOKEN` з токеном, на який у вас є дозвіл. Cloudflare Dashboard → Worker → Settings → Variables and Secrets → Add → **Secret** → `KODIK_TOKEN`. Не публікуйте ключ у репозиторії чи чаті. Після налаштування та нового деплою `GET /api/providers` показує `kodik.enabled: true`, а `/api/search` надсилає багатоваріантний пошук до Kodik. Без токена `provider_count: 0` — очікувано. Адаптер на цьому етапі повертає **тільки метадані**; пошук і відтворення в UI поки здійснюються через Online MOD.

## Тимчасовий публічний Kodik token

Якщо `KODIK_TOKEN` не задано, Worker пробує отримати публічний токен із скрипта Kodik player через механізм, описаний у відкритій бібліотеці `kodikwrapper`. Токен кешується 30 хвилин тільки в пам'яті Worker і не повертається користувачу. Підтримка такого токена або дозвіл на його використання Kodik не гарантуються. За наявності власного `KODIK_TOKEN` він має пріоритет. Статус `provider_count: 1` означає наявність адаптера, а не успішну авторизацію. Для реального тесту викличте `/api/search?title=Matrix&year=1999` і перевірте `provider_status` та `results`.

## Українські джерела

UAFILM, UASerials і UAKino позначені як **очікує API для Lampa**. Попередній браузерний вебпошук видалений; натискання не відкриває зовнішніх вкладок. Поки немає підтвердженого придатного API чи підтримуваного URL потоку, ці пункти не можуть запускати відео. Filmix/HDRezka/Kodik лишаються через Online MOD, де результати і плеєр працюють у Lampa за доступності зовнішнього сервісу.


## Автопошук і пряме відтворення в Lampa

У кнопці ХОТ є пункт **Автопошук · усі доступні джерела**: він надсилає назву, альтернативні назви, TMDB ID та рік на `/api/search`. У результатах показуються лише записи, які містять прямі HTTPS URL формату `.m3u8`, `.mp4` або `.mpd`. Вибір запускає `Lampa.Player.play` без відкриття браузера.

Для власного каталогу потоків, які можна законно відтворювати, у Cloudflare Worker задайте `XOT_CATALOG_URL` (HTTPS endpoint з відповіддю JSON `{"results":[{"title":"Назва","year":2026,"source":"Моє джерело","translation":"Українська","quality":"1080p","url":"https://media.example/video.m3u8"}]}`). Worker передає `title`, `year` та `tmdb_id` як параметри запиту. Зберігайте каталог за довіреним HTTPS URL; Worker не обходить географічні обмеження, DRM чи авторизацію. Без `XOT_CATALOG_URL` каталог вимкнений, результати Kodik із embed-посиланнями не передаються у плеєр.

**Поточна межа:** Filmix, HDRezka, UAKino, UASerials та UAFILM поки НЕ мають незалежних перевірених адаптерів, які повертають прямі потоки. Для Filmix/Rezka збережено Online MOD; його пошук не входить в агрегатор `/api/search`. Нова функція є готовим потоком UI → Worker → Lampa.Player, але не означає автоматичну появу відео з непідключених сервісів.

## Окремі налаштовувані UA-адаптери

Worker підтримує власні HTTPS JSON endpoints через змінні середовища:
- `XOT_UAKINO_API_URL` → `provider=uakino`
- `XOT_UASERIALS_API_URL` → `provider=uaserials`
- `XOT_UAFILM_API_URL` → `provider=uafilm`
- `XOT_FILMIX_API_URL` → `provider=filmix_api`
- `XOT_REZKA_API_URL` → `provider=rezka_api`

Це **контракт адаптерів** для власного/дозволеного JSON API, а не URL оригінального вебсайту. Очікувана відповідь: `{"results":[{"title":"Example","year":2026,"url":"https://media.example/video.m3u8","quality":"1080p","translation":"UA","source":"UAKino"}]}`. Кожен endpoint одержує параметри `title`, `year`, `tmdb_id`. Вхідні результати без HTTPS прямого потоку відкидаються. За відсутності відповідної змінної джерело показує стан «не підключено», не відкриваючи браузер. Реальні API з підтвердженим правом видавати потоки потрібні окремо.
