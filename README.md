# XOT Online — ХОТ для Lampa

Плагін Lampa з кнопкою **ХОТ** і меню зовнішніх джерел через Online MOD.

## Джерела у меню

- Filmix
- HDRezka
- Kodik
- CDNVideoHub
- AniLibria

Ці джерела використовують **сторонній Online MOD** (із дозволу користувача); це не незалежні парсери. Їхні доступність і якість залежать від сервісу, мережі та умов акаунта. Власний серверний реєстр наразі порожній.

**Internet Archive повністю вилучено** з меню, Worker API та тестів за запитом користувача. `/api/health` має повертати `provider_count: 0` — це очікувано, бо він показує тільки незалежні серверні провайдери.

## Встановлення

```
https://xot-online.ai-beta69690.workers.dev/m.js
```

Якщо Cloudflare підключений до GitHub, після нового коміту перевір успішність збірки. Перезапусти Lampa для завантаження змін.

## Safari

Плагін встановлює темний `meta[name=theme-color]` (`#171717`) для браузерної панелі. На деяких версіях iOS Safari колір панелі визначається оформленням базового сайту Lampa або системними налаштуваннями. Плагін не перевизначає глобальний фон Lampa, щоб не зламати інтерфейс; тому темний колір Safari не гарантується.

## API

- `GET /api/health` — стан Worker.
- `GET /api/providers` — незалежні серверні адаптери (поки порожній список).
- `GET /api/search` — інфраструктурний маршрут для майбутніх API.

## Власний Kodik search API

Адаптер Kodik підключається **лише** після додавання секрету Worker `KODIK_TOKEN` з токеном, на який у вас є дозвіл. Cloudflare Dashboard → Worker → Settings → Variables and Secrets → Add → **Secret** → `KODIK_TOKEN`. Не публікуйте ключ у репозиторії чи чаті. Після налаштування та нового деплою `GET /api/providers` показує `kodik.enabled: true`, а `/api/search` надсилає багатоваріантний пошук до Kodik. Без токена `provider_count: 0` — очікувано. Адаптер на цьому етапі повертає **тільки метадані**; пошук і відтворення в UI поки здійснюються через Online MOD.

## Тимчасовий публічний Kodik token

Якщо `KODIK_TOKEN` не задано, Worker пробує отримати публічний токен із скрипта Kodik player через механізм, описаний у відкритій бібліотеці `kodikwrapper`. Токен кешується 30 хвилин тільки в пам'яті Worker і не повертається користувачу. Підтримка такого токена або дозвіл на його використання Kodik не гарантуються. За наявності власного `KODIK_TOKEN` він має пріоритет. Статус `provider_count: 1` означає наявність адаптера, а не успішну авторизацію. Для реального тесту викличте `/api/search?title=Matrix&year=1999` і перевірте `provider_status` та `results`.
