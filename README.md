# XOT Online — ХОТ для Lampa

Кнопка **ХОТ** у картці фільму або серіалу одразу відкриває екран результатів Online MOD: картка ліворуч, пошук, **Балансер** і фільтри зверху. Проміжний вибір джерела більше не потрібен.

## Встановлення й оновлення

Додайте в плагіни Lampa:

```text
https://xot-online.ai-beta69690.workers.dev/m.js
```

Після оновлення перезапустіть Lampa. Якщо зберігся старий статус 404, видаліть запис плагіна й додайте цю саму адресу знову. Worker має повертати HTTP 200, JavaScript і `Access-Control-Allow-Origin: *` для `/m.js` та `/online.js`.

## Перегляд і балансери

1. Відкрийте картку → **ХОТ**. За відсутності збережених налаштувань вибирається Filmix.
2. Угорі відкрийте **Балансер** і виберіть інше джерело. Online MOD очищує попередні результати та запускає пошук для поточної картки в обраному джерелі.
3. Виберіть озвучення, сезон/серію та якість і запустіть перегляд у Lampa.

Зберігається останній глобальний балансер. Якщо в Online MOD увімкнено запам’ятовування балансера для кожного фільму, ця настройка має пріоритет. Передаються назва, оригінальна назва, альтернативні назви, дата, TMDB/IMDb та інші ідентифікатори картки. Для серіалів `name` і `original_name` також нормалізуються до полів, які читають адаптери.

Модуль завантажується під час першого натискання, без додаткового діалогу. Використовується сторонній [Online MOD](https://github.com/nb557/plugins/blob/851bcc9bc064ac06dc2b0e7ff6631baba61be511/online_mod.js), зафіксований на цій ревізії. Він виконується в контексті Lampa та має доступ до її сховища й картки. Уже встановлений Online MOD використовується повторно. При помилці мережі або таймауті показується повідомлення; наступне натискання дозволяє повторити завантаження.

У модулі доступні Filmix, HDRezka, Kodik, CDNVideoHub, AniLibria та інші ввімкнені ним адаптери. Перемикання запускає пошук **вибраного** балансера; це не паралельний пошук усіх сторонніх сервісів. Наявність відео, авторизація, якість і доступність конкретного сервісу залежать від самого сервісу, мережі та акаунта.

## Незалежні API

Довге натискання ХОТ на пульті або контекстне меню кнопки відкриває додатковий екран джерел і діагностики. Тут збережено власний експериментальний Filmix-адаптер, прив’язку пристрою за кодом і налаштовані JSON-каталоги.

За замовчуванням усі незалежні провайдери вимкнені. `provider_count: 0` у `/api/health` означає відсутність налаштованих серверних адаптерів; це не кількість балансерів Online MOD. Непідключені джерела не повертають вигаданих потоків.

Підтримувані змінні Cloudflare Worker:

| Змінна | Провайдер |
| --- | --- |
| `XOT_CATALOG_URL` | `catalog` |
| `XOT_UAKINO_API_URL` | `uakino` |
| `XOT_UASERIALS_API_URL` | `uaserials` |
| `XOT_UAFILM_API_URL` | `uafilm` |
| `XOT_FILMIX_API_URL` | `filmix_api` |
| `XOT_REZKA_API_URL` | `rezka_api` |
| `KODIK_TOKEN` | `kodik` — лише метадані, без прямого потоку |

URL має вказувати на власний/дозволений HTTPS JSON API, а не головну сторінку сайту. Запит передає `title`, `year`, `tmdb_id`. Приклад відповіді:

```json
{"results":[{"title":"Example","year":2026,"url":"https://media.example/video.m3u8","quality":"1080p","translation":"Українська"}]}
```

Worker шукає відомі варіанти назви, перевіряє збіг назви та року і відкидає результати без прямих HTTPS `.m3u8`, `.mp4` або `.mpd` URL. Адаптери UAKino, UASerials, UAFILM і Rezka є контрактами для підключення API, а не готовими парсерами цих сайтів.

Власний Filmix використовує `POST /api/filmix`: `probe`, `pair`, `confirm`, `search`, `post`, `profile`. Код вводиться у власному акаунті на [filmix.gg/consoles](https://filmix.gg/consoles). Токен зберігається на пристрої в `Lampa.Storage`, передається Worker у POST і не записується у репозиторій. Ліміт якості залежить від відповіді профілю Filmix. Це експериментальний адаптер: доступність HTTPS API та відтворення на конкретному пристрої потрібно перевіряти окремо.

## API

- `GET /api/health` — стан Worker і кількість налаштованих незалежних адаптерів.
- `GET /api/providers` — реєстр та стан конфігурації адаптерів.
- `GET /api/query-plan?title=Example&alt=Other&year=2026` — варіанти пошуку.
- `GET /api/search?title=Example&year=2026&provider=catalog` — пошук у налаштованих API.
- `POST /api/filmix` — власний Filmix-адаптер.

## Розробка та перевірки

```bash
npm install
npm test
npm run dev
npm run deploy
```

Канонічні файли плагіна лежать у `public/`; Worker публікує саме їх. Після редагування виконайте `npm run sync`, щоб оновити копії в корені для raw GitHub URL. Тести та деплой перевіряють однаковість копій.

Тести виконують плагін у середовищі з API Lampa та перевіряють прямий перехід, поля картки, вибір балансера, повторні натискання, помилки завантаження, таймаут, ранній старт і маршрути Worker. Filmix перевіряється з модельованими відповідями API. Ці тести не підтверджують доступність усіх зовнішніх балансерів або реальне відтворення на телевізорі.
