# ХОТ — власні балансери для Lampa

Версія 0.3.15 відкриває **власний** компонент `xot_online`: картка ліворуч, пошук і перемикач **Балансер** зверху, озвучення/серії справа. Плагін не завантажує Online MOD або Lumio. Filmix, Eneyida, KinoVezha, UASerials, Serialno, UFDub і HDRezka мають окремі адаптери в цьому репозиторії. Аніме-джерела вилучені з меню й пошуку.

## Поточний режим — без оренди

У версії 0.3.10 UAKino/Ashdi вилучено з балансерів, загального й резервного пошуку, реєстру додаткових API та Worker-адаптерів. У 0.3.12 старий збережений вибір вилученого або вимкненого джерела відкриває **Усі джерела**. Причини попередньої перевірки залишені лише в [архіві дослідження джерел](docs/source-candidates.md).

За рішенням користувача працюємо на наявному Cloudflare Worker, без VPS і додаткових платних сервісів. Відео відтворюється безпосередньо з HTTPS CDN джерел; Worker обробляє пошук і метадані. Підключення `XOT_BACKEND_URL` не налаштоване. Серверний набір у `server/` збережений як необов’язковий варіант на майбутнє.

[Безкоштовний тариф Workers](https://developers.cloudflare.com/workers/platform/limits/) має ліміти 100 000 запитів на день і 10 мс CPU на запит. Поточна реалізація не вимагає платних KV, R2, Containers або VPS.

## HDRezka: поточна перевірка

28.10.2026 повторно перевірено сторінку фільму та гостьовий API з Cloudflare. Обидва шляхи повернули обмеження доступу. Для VIDAA та звичайного браузера сам Worker наразі не забезпечує підтверджене відтворення Rezka. Пошук і дублікати озвучень виправлені в підготовленій 0.3.16, але це не оголошується робочим підключенням. [Повний звіт](docs/rezka-access-2026-10-28.md). Опублікована версія залишається 0.3.15.

## Встановлення

```text
https://xot-online.ai-beta69690.workers.dev/m.js
```

Після оновлення перезапустіть Lampa. Кнопка **ХОТ** для нової картки одразу відкриває **Усі джерела**. Раніше обране джерело запам’ятовується тільки для конкретної картки й використовується, якщо воно увімкнене. Глобальний останній вибір не обмежує нові картки. Кнопка має власний SVG-значок і розміщується поруч із кнопками перегляду перед закладками та іншими службовими діями. Через **Балансер** можна змінити джерело, через окрему кнопку **Озвучення** поруч із ним — вибрати студію або повернути всі озвучення. Вибір запам’ятовується окремо для картки й балансера. Через **Фільтр** можна вибрати сезон, повторити пошук, налаштувати балансери, відкрити діагностику й керувати Filmix-акаунтом. Вибір рядка відео запускає вбудований плеєр Lampa; доступні якості передаються його перемикачу. Позиція перегляду зберігається через Lampa.Timeline.

### Зручний перегляд у 0.3.15

**Фільтр → Зручний перегляд** об’єднує профілі якості (720p/1080p/максимальна), розумне сортування, мову/розмір/затримку субтитрів і налаштування заставки серіалу. Кнопка цих налаштувань також є в панелі власного плеєра. Пропуск заставки виконується лише після натискання. **Фільтр → Серії та сезони** показує назви, дати та описи за вибором; майбутні серії позначені окремо. **Відстеження серіалу / Нові серії** перевіряє до трьох збережених серіалів під час відкриття без спливаючих вікон. Усі подробиці, межі та результати перевірки Kinobase/HDVB/UAFlix — у [описі 0.3.15](docs/comfort-0315.md). Ці три кандидати не пройшли перевірку доступності відео, тому до робочих джерел не додані.

### Прогрес, продовження й улюблені озвучення

- Біля фільмів та серій показуються час, відсоток і смужка перегляду. Від 90% з’являється позначка **Переглянуто**, відповідно до порога продовження Lampa. Старі хеші XOT збережені: прогрес спільний для балансерів, якостей та озвучень тієї самої картки/серії. Він читається й записується через штатний `Lampa.Timeline`; за наявності API `link` записи також прив’язуються до картки. Непідтверджений ручний збіг не отримує прогрес відкритої картки.
- Рядок **Продовжити** над результатами обирає останній незавершений фільм або серію з усіх доступних сезонів. Для старих записів без часових міток обирається пізніша незавершена серія. Потрібна збережена позиція в секундах: відсоток без часу сам по собі не створює вигаданого тайм-коду. Кнопка відновлює позицію без другого запиту підтвердження й без зміни налаштування `player_timecode`. Переглянуті серії пропускаються. Якщо потрібного потоку немає, залишається інформація **Останній перегляд** без кнопки запуску; інша серія не підставляється.
- При продовженні ручний вибір озвучення має пріоритет, далі враховується список улюблених, а потім попереднє озвучення. Якщо відома попередня студія зникла або її ID тепер позначає інше озвучення, потрібен явний вибір. Адреса отримується через звичайний свіжий шлях відтворення; закриття скасовує очікування. Скасування до готовності відео не перезаписує старий прогрес нулем.
- Для пошуку попереднього сезону й озвучення зберігаються лише метадані останніх 200 переглядів у локальному сховищі. Запис створюється після початку відтворення; невдалий запуск не стає останнім переглядом. Додатковий індекс відокремлений за профілем `Timeline.filename()`, типом картки та її джерелом. Посилань на відео чи особистих токенів у ньому немає. Зовнішні плеєри залежать від того, чи повертають вони прогрес у Lampa; живі перевірки нижче використовують вбудований плеєр.
- Утримання **OK** на рядку фільму/серії або правий клік відкриває **Позначити переглянутим**, **Позначити не переглянутим** чи **Скинути прогрес** залежно від поточної позначки. Те саме меню доступне через **Фільтр → Позначки перегляду**, з вибором іншої серії та діями для сезону. Позначки сезону змінюють лише відомі серії (кількість показана в меню), один раз на серію незалежно від числа озвучень. Вони не створюють історію фактичного запуску відео.
- **Скасувати останню зміну** у цьому меню відновлює попередні відсоток, час і тривалість. Скасування зберігається після повторного відкриття картки, прив’язане до картки й профілю Lampa та не перезаписує новіший прогрес перегляду. Зберігаються лише позначки, без відеопосилань або облікових даних.
- Якщо незавершеного перегляду немає, над списком з’являється **Наступна непереглянута** після останньої завершеної серії. Вона не пропускає прогалин у нумерації та недоступну найближчу серію, не запускається автоматично й не переносить час із попередньої серії. Вибір озвучення враховує ручне налаштування, улюблені студії та попередню озвучку; коли її немає, пропонується вибір. Для прямого переходу між сезонами потрібна відома кількість серій попереднього сезону; інакше спокійний рядок **Наступний сезон** лише відкриває список. Поки триває загальний пошук, ця дія не показується. Одночасно показується тільки одна основна дія: продовження або наступна серія/сезон.
- **Фільтр → Улюблені озвучення** або **Озвучення → Улюблені озвучення · налаштувати** дозволяє додати доступні озвучення поточної картки, змінити порядок і прибрати їх. Список діє для всіх карток. Ручний вибір конкретної студії або **Усі озвучення** залишається головним; автоматичний вибір не записується як ручний. **Автовибір: улюблені, потім українська** повертає автоматичний режим. Якості в назві на зразок 720p/1080p не розділяють ту саму студію, але мова та різні назви студій зберігаються. За однакового пріоритету враховується порядок балансерів. Нова картка не отримує чужий ручний вибір.

### Налаштування джерел, кеш і діагностика

- **Фільтр → Налаштування балансерів** дозволяє увімкнути/вимкнути джерело та перемістити його вище або нижче. Порядок визначає перелік балансерів і пріоритет однакових потоків у загальному списку. Зміни застосовуються один раз після **Готово** або виходу назад. Вимкнені джерела не отримують запитів у загальному й резервному пошуку та не показуються в перемикачі. Початково вимкнені UFDub і HDRezka; їх можна увімкнути тут. AniLibria відсутня в меню, а AniTube не додавали. Якщо вимкнути все, налаштування залишаються доступними; є відновлення початкового вибору.
- У **Усі джерела** повністю однаковий набір адрес і якостей одного озвучення/серії з різних каталогів об’єднується в рядок із назвами всіх джерел. Відтворюється джерело, яке стоїть вище у вашому порядку. Різні студії, номери серій, аудіодоріжки, адреси з іншими параметрами або різні набори якостей залишаються окремими. Усі вихідні озвучення залишаються доступними у фільтрі, а черга серій зберігає обране джерело.
- Кеш пошуку живе лише в пам’яті плагіна: до 5 хвилин для знайдених метаданих, до 1 хвилини для порожнього пошуку, максимум 80 записів. Назва, рік і тип картки входять у ключ. Помилки, скасовані запити, особисті токени та автентифіковані пошуки Filmix не кешуються. Адреси відео, `post`, `stream` та додаткові JSON-провайдери не кешуються. **Повторити пошук** і **Повторити пошук без кешу** очищають кеш і виконують новий пошук.
- **Фільтр → Діагностика пошуку** показує знайдені варіанти, відсутність підтвердженого збігу, неоднозначність, помилку доступу, вимкнене джерело або пропуск джерела лише для серіалів. Видно пошукові назви та використання кешу. Звідси можна відкрити окремий балансер або повторити пошук. Основний список і надалі приховує порожні та недоступні джерела.

## Перевірений стан

### Усі джерела, мова, якість і наступна серія

- **Балансер → Усі джерела** шукає поточну картку одразу в доступних адаптерах. Результати з’являються поступово з назвою джерела, озвученням та якостями. Помилка або таймаут одного джерела не прибирає вже знайдені потоки інших. Збіги звіряються з назвою, роком і типом картки. У списку залишаються знайдені відео та підтверджені озвучення. Порожні, неоднозначні й недоступні джерела та службові статуси приховані. Недоступні озвучення також не додають зайвих пунктів до загального вибору озвучень і сезонів. До перших результатів видно загальний індикатор пошуку; якщо нічого не знайдено, залишається одне повідомлення з кнопкою повторного пошуку. Через верхній перемикач можна відкрити будь-який окремий балансер і побачити причину його помилки або недоступності озвучення.
- **Українська автоматично** ввімкнена за замовчуванням: за відсутності улюбленого озвучення обираються варіанти з явною українською мовною позначкою. Назва студії сама по собі не визначає мову. Ручний вибір конкретного озвучення або «Усі озвучення» має пріоритет і запам’ятовується. Пункт **Озвучення → Автовибір української** (або **Автовибір: улюблені, потім українська**, якщо є список улюблених) повертає автоматичний режим. Український автовибір можна вимкнути у **Фільтрі**. Без улюбленої студії в режимі всіх джерел показуються українські варіанти з різних балансерів.
- **Фільтр → Бажана якість** зберігає стандартне налаштування Lampa `video_quality_default`. Ручна зміна якості у вбудованому плеєрі ХОТ також його оновлює. Якщо бажаної якості немає, обирається доступна нижча (або найменша доступна, якщо нижчих немає), а бажане значення зберігається для наступного відео. Доступність 2160p та ліміти акаунта визначає джерело.
- **Наступна серія** та список серій працюють у вбудованому плеєрі Lampa. Черга впорядкована за сезоном і номером серії, зберігає те саме джерело й озвучення та може переходити між сезонами. Інші студії не підставляються автоматично. Плейліст конкретної серії отримується лише при її виборі. Автоперехід після завершення використовує стандартне налаштування Lampa `playlist_next`. Зовнішні плеєри можуть не підтримувати таку динамічну чергу.

Усі чотири функції перевірено у справжній Lampa/Chromium. Перевірка включає повільне джерело, окрему помилку, чужий фільм того самого року, ручний вибір мови, збереження бажаних 2160p при фактичному потоці 480p, зміну на 720p і реальне відтворення наступної серії. Запізніла відповідь не відкриває вже закритий плеєр.

### Резерв при помилці плеєра

Якщо вбудований плеєр повідомляє про фатальну помилку або не готовий до відтворення протягом 15 секунд, ХОТ шукає **резервне джерело** для тієї самої підтвердженої картки. Для серіалу потрібен точний збіг сезону й номера серії. Меню показує джерело, озвучення та доступні якості; перемикання відбувається після вибору користувача. Новий плеєр відновлює час і будує чергу наступних серій обраного озвучення. Це позиція за часом; різні монтажні версії можуть мати часові розбіжності.

Хостинг, на якому виникла помилка, та його відомі спільні дзеркала виключаються з резерву. Пошук має загальний таймаут 20 секунд; помилка окремого джерела не скасовує решту. Якщо нічого немає, доступний повторний пошук. Закриття плеєра скасовує запити й запізнілі меню. Ручний непідтверджений збіг іншого фільму не запускає резервний пошук за початковою карткою. Автоматичне меню стосується вбудованого плеєра Lampa, який передає події помилок і готовності.

У Lampa/Chromium перевірено перехід із Eneyida на українське DniproFilm у Filmix для **Короля Талси, сезон 2, серія 1, з 65-ї секунди**, а потім відтворення серії 2 у новій черзі. Якість резерву визначає джерело: анонімний Filmix у цьому тесті повернув 480p/360p. Інші фільми та спільні несправні дзеркала не пропонувалися.

| UASerials | Власний пошук і читання конфігурації вкладок плеєра. У Lampa/Chromium відтворено фільм у 720p/1080p та першу серію другого сезону «Короля Талси». |
| Serialno · серіали | Власний пошук серіалів. У Lampa/Chromium через Cloudflare відтворено «Ззовні» 1×1 і 1×2 у 1920×960 (кінематографічний 1080p), перевірено наступну серію зі збереженням озвучення. Для картки фільму запити пропускаються. |
| UFDub | Окремий відеохостинг `api.ufdub.com`. У Lampa/Chromium відтворено «Небесні створіння» (1994) і дві серії «РОКУХОДО» у 1920×1080; перевірено перемотування й наступну серію. Без акаунта або VPS. |
| HDRezka | Власний пошук із Worker знаходить фільм. Сторінка плеєра в поточній перевірці повертає «Проверяем, что вы не бот!». Це показується як обмеження доступу, а не як відсутність фільму. Реальне відтворення Rezka з Worker поки не підтверджено. |
| Власні JSON API | Підключаються окремо; неввімкнені джерела не показуються як робочі. |

Filmix API зараз має некоректний HTTPS-сертифікат. Тому **лише анонімні** пошук/читання відео можуть перейти на його публічний HTTP endpoint. Для кожного такого запиту створюється новий неприв’язаний device ID. Особисті токени, прив’язка пристрою й профіль працюють **тільки через HTTPS**, без послаблення перевірки сертифіката. Клієнт звертається до Worker по HTTPS, а у плеєр допускаються тільки HTTPS URL. Доступна якість визначається відповіддю Filmix та станом акаунта. Повний перелік озвучень зберігається окремо від придатних потоків: якщо для озвучення є лише якість вище поточного ліміту, воно залишається в списку з поясненням і не видається за доступне для відтворення. Для серіалів більше немає обрізання плоского списку після 350 рядків.

Автоматичний пошук звіряє повну назву, рік і тип контенту з відкритою карткою. Інший фільм того самого року або продовження зі схожою назвою не потрапляє в список. Підтверджена локалізована назва Filmix допомагає шукати ту саму картку в Rezka. Для ручного пошуку через поле вгорі можна переглядати ширші результати.

HDRezka отримується через HTML-парсер і публічні AJAX дії `get_movie`, `get_episodes`, `get_stream`. Перенаправлення дозволені лише на відомі HTTPS-адреси сервісу. CAPTCHA та обмеження доступу не обходяться.

Eneyida використовує пошук самого сайту й публічні плеєри HDVB UA/Tortuga. Трейлери не потрапляють у список потоків, скрипти сторінок не виконуються. Якості визначаються HLS-плейлістом, тому 2160p показується лише за наявності відповідного варіанта. Для перевіреної «Оселі зла» доступні 480p/720p/1080p. Серіали зберігають сезони та озвучення; відеоплейліст запитується при виборі конкретної серії. Якщо HLS має окремі аудіодоріжки, зберігається майстер-плейліст із режимом «Авто», щоб не втратити звук. Worker не проксіює відеобайти. [Перевірка інших кандидатів](docs/source-candidates.md).

KinoVezha й UASerials мають власні каталоги, але частково використовують спільний з Eneyida відеоархів. Їхній основний Tortuga-плеєр із Cloudflare зараз повертає HTML 404 зі статусом 200. Для відомих публічних адрес `vod/vid` та `embed/embd` адаптер може перевірити HDVB UA: крім ідентифікатора, повна оригінальна назва та рік фільму мають збігатися з читабельним ім’ям HLS-медіафайлу. Для серіалів звіряється назва. Непідтверджені й непрозорі адреси дзеркала не повертаються. Це додаткові каталоги, а не гарантія незалежного резервного відеохостингу.

Serialno використовує такий самий контрольований доступ до опублікованого плеєра та перевіреного публічного архіву. Його каталог теж частково перетинається з Eneyida/UASerials. Трейлери та Ashdi-вкладки не використовуються. Якщо в пошуковій картці немає оригінальної назви, перевіряються метадані максимум чотирьох сторінок відповідного року; їхні плеєри під час цього пошуку не запитуються. Перед отриманням відео ще раз перевіряються назва, рік і тип. Назва студії сама по собі не позначає українську мову; для дзеркала мова не вгадується з мови каталогу.

UFDub використовує власний каталог і лише серії/редакції, опубліковані основним плеєром для гостя. Доступні потоки входять також у **Усі джерела** й резервний пошук. Сторінка фільму повторно звіряється за назвою, роком і типом; застарілі оригінальні назви шаблону пошуку ігноруються. Перший MP4 підтверджується при відкритті, наступні серії отримують адресу лише перед запуском. Скрипти сайту не виконуються, відеобайти не проходять через Worker. Заголовок перенаправлення з українським ім’ям файлу декодується як дані, а медіа допускається тільки з відомого HTTPS-хоста. Для цих звичайних MP4 використовується HTML5-відтворення без атрибута `crossorigin`, оскільки сервер не надає CORS-заголовків; інші джерела зберігають свій режим. Вибір якості — **Авто**: плеєр надає один файл на серію, а не окремі 720p/1080p/2160p. Перевірені файли мають 1080p, але це не гарантія для всього каталогу. Формати `web` і відео з окремим аудіофайлом поки пропускаються.

UAFlix не додано: під час перевірки каталог із Cloudflare повернув лише трейлер замість основного плеєра. Поруч було загальне повідомлення з порадою авторизуватися або змінити країну; точну причину відмінності видачі не встановлено. Попередня доступність окремого HLS не підтвердила доступності каталогу.


## Додаткові джерела з прикладу Lumio

[Розбір наданого прикладу](docs/source-audit.md). Lumio використовує власний сервер Lampac/Mitsu і його протоколи доступу. Наявність назви в його меню не означає наявності незалежного робочого адаптера в ХОТ. Код Lumio й його VIP-токени не імпортуються в плагін.

## Worker або власний VPS

За замовчуванням усе виконується на Cloudflare Worker. Для запуску **тих самих власних адаптерів** на звичайному Linux-сервері підготовлено Node backend, Docker Compose, Caddy/HTTPS і приватний канал Worker → backend. Адреса плагіна при цьому залишається та сама. [Розгортання VPS](server/README.md).

Для підключення сервера у Worker задаються:

- `XOT_BACKEND_URL` — HTTPS origin вашого API, наприклад `https://api.example.com`.
- `XOT_BACKEND_TOKEN` — секрет Worker, який збігається з `XOT_SERVER_TOKEN` на сервері.

Це переносить виконання адаптерів; саме по собі не додає Lampac, акаунти сервісів або гарантію доступу до Rezka. Після запуску на VPS кожен сервіс перевіряється окремо.

## API

- `GET /api/health` — Worker, список `native_balancers` і кількість налаштованих JSON API.
- `POST /api/filmix` — `probe`, `pair`, `confirm`, `search`, `post`, `profile`.
- `POST /api/anilibria` — збережений API сумісності; у меню та пошуку плагіна не використовується.
- `POST /api/eneyida` — `search`, `post`, `stream`; якості фільму визначаються одразу, серії — при виборі.
- `POST /api/kinovezha`, `POST /api/uaserials` — `search`, `post`, `stream` через власні адаптери каталогів.
- `POST /api/ufdub` — `search`, `post`, `stream`; основний публічний MP4-плейліст і завантаження адрес вибраних серій.
- `POST /api/serialno` — `search`, `post`, `stream`; каталог серіалів і відкладене отримання якостей вибраної серії.
- `POST /api/rezka` — `probe`, `search`, `post`, `episodes`, `stream`.
- `GET /api/providers` — додаткові JSON API та стан їхньої конфігурації.
- `GET /api/search?title=Example&year=2026&provider=catalog` — пошук у налаштованих каталогах.

У `/api/health` поле `provider_count` рахує тільки додаткові налаштовані API. `native_balancers: ["filmix", "eneyida", "kinovezha", "uaserials", "ufdub", "serialno", "rezka", "anilibria"]` — реалізовані серверні API, а не обіцянка доступності сторонніх сервісів. Меню й фактичні запити залежать від налаштувань; AniLibria виключена з клієнта.

Підтримуються змінні `XOT_CATALOG_URL`, `XOT_UASERIALS_API_URL`, `XOT_UAFILM_API_URL`, `XOT_FILMIX_API_URL`, `XOT_REZKA_API_URL`. Кожна має вказувати на власний/дозволений HTTPS JSON API, а не головну сторінку сайту. Формат відповіді:

```json
{"results":[{"title":"Example","year":2026,"url":"https://media.example/video.m3u8","quality":"1080p","translation":"Українська"}]}
```

`KODIK_TOKEN` вмикає тільки серверний пошук метаданих Kodik; цей адаптер не заявляється як власне джерело потоків.

## Розробка й перевірка

```bash
npm ci
npm test
npm run dev
npm run deploy
```

Канонічні файли — `public/m.js` та `public/online.js`. Після редагування виконайте `npm run sync`; тести й деплой перевіряють однаковість копій у корені. Деплой зберігає наявні змінні Worker. CI перевіряє синтаксис, адаптери, приватний backend, маршрути та збірку Wrangler.

Для живої браузерної перевірки потрібен Chromium, встановлений для `playwright-core`, або змінна `PLAYWRIGHT_EXECUTABLE_PATH` з його шляхом:

```bash
npm run smoke
# Тестова публікація:
XOT_TEST_ORIGIN=https://your-preview.workers.dev npm run smoke
# Eneyida: реальне відтворення 720p/1080p та вибір сезону/серії
npm run smoke:eneyida
npm run smoke:kinovezha
npm run smoke:uaserials
npm run smoke:ufdub
npm run smoke:serialno
npm run smoke:sources
npm run smoke:watch
npm run smoke:favorite-voices
npm run smoke:features
npm run smoke:backup
XOT_BACKUP_AGGREGATE=1 npm run smoke:backup
# Нові локальні скрипти проти реальних API до публікації:
XOT_LOCAL_ASSETS=1 npm run smoke:features
```

Ця ручна перевірка відкриває справжню Lampa, передає подію картки фільму, завантажує публічний `m.js`, перевіряє Filmix-відтворення та верхнє меню HDRezka. Окремо перевіряються видимість значка до наведення, позиція кнопки між плагіном перегляду та закладками, вибір українського озвучення через кнопку зверху й відновлення цього вибору після повторного відкриття картки. У звіті Rezka може мати `restricted`; це не успішна перевірка її відтворення. Зовнішня мережа, сервіси та конкретні телевізори перевіряються окремо від детермінованих тестів.

Спільний сценарій `scripts/smoke-public-players.mjs` для Eneyida, KinoVezha й UASerials відкриває джерело через справжнє меню **Балансер**, перевіряє фактичну ширину кадру 1280/1920 та тривалість фільму понад 6000 секунд. Потім відкриває серіал, обирає другий сезон через **Фільтр** і перевіряє, що запитується відео лише однієї обраної серії.

`smoke:ufdub` перевіряє реальний MP4-фільм, перемотування, серії 1→2, відкладене отримання наступного посилання, скасування після закриття плеєра й серії UFDub у загальному пошуку. Фактичні розміри кадру фіксуються з HTML5 video; для цього джерела не створюються вигадані варіанти якості.

`smoke:serialno` відтворює справжні серії «Ззовні» з Worker та перевіряє перехід 1×1 → 1×2, якість кадру й відсутність запитів до Ashdi/аніме-джерел. `smoke:sources` використовує справжню Lampa з контрольованими відповідями API для перевірки початкового загального пошуку, об’єднаних рядків, збереження озвучень, налаштування порядку й вимкнення джерел, одноразового застосування змін, кешу пошуку без кешування `post`, примусового повтору та відновлення після вимкнення всіх джерел. Тестові відео не відтворюються.

`smoke:watch` у справжній Lampa відновлює «Оселю зла» з 2760-ї секунди при `player_timecode=again` і «Короля Талси» 2×2 з 720-ї секунди при `ask`, без другого діалогу. Він перевіряє смужки/позначки, вибір серії з іншого сезону, пропуск переглянутого, збереження позначки після скасування завантаження, скасування пізнього запуску та відсутність відеоадрес у локальному індексі. `smoke:favorite-voices` перевіряє інтерфейс на контрольованих каталогах без запуску тестових потоків: пріоритети між картками, ручний вибір і «Усі озвучення», порядок, повернення в автоматичний режим, явний вибір після зникнення студії та неактивне продовження за відсутності потоку.

`smoke:backup` інжектує фатальну подію у справжній плеєр, обирає реальний потік іншого CDN, звіряє сезон/серію/час, наступну серію, резерв із режиму «Усі джерела», завислий запуск (меню через приблизно 16 секунд), скасування запізнілого резерву та закриття його меню разом із плеєром.

Сценарій `smoke:features` також перевіряє приховування порожніх і недоступних джерел у загальному списку, недоступного озвучення та його сезону у фільтрах, спільне повідомлення за відсутності результатів і збереження пояснень при відкритті окремого балансера. Він явно вмикає HDRezka для перевірки помилки окремого джерела. Відновлення після збереженого вибору вилученого/вимкненого балансера перевіряють модульні тести.
