# Власний backend ХОТ на недорогому VPS

**Відкладено:** користувач обрав роботу на безкоштовному Worker без оренди. Цей набір наразі не використовується.

Це необов’язковий Node-сервер для тих самих Filmix/Rezka адаптерів. Cloudflare Worker продовжує віддавати плагін і перенаправляє тільки `/api/filmix` та `/api/rezka` на ваш сервер по HTTPS. Приватний серверний токен зберігається у Worker Secret і на VPS, не у браузері.

Підготовлено код, Compose і HTTPS-конфігурацію; сервер ще не орендований і не розгорнутий. Локально перевірені авторизація, маршрути, обмеження запитів та делегування. Docker-збірка потребує перевірки на сервері з Docker. Вихід із іншої мережі не гарантує доступу до HDRezka: поточну CAPTCHA/обмеження потрібно перевірити після запуску.

## Недорогий кандидат

На 26 жовтня 2026 офіційна сторінка [OVHcloud VPS-1](https://www.ovhcloud.com/en-ie/vps/) показує **від €3,81/місяць без ПДВ**, 2 vCPU, 4 GB RAM, 40 GB NVMe, 500 Mbps. Перед оплатою потрібно перевірити країну, податки, строк зобов’язань, ціну поновлення й доступність. Це пропозиція для розгляду, не вже оформлене замовлення.

Такий сервер є початковим кандидатом для метаданих і невеликого числа запитів. ХОТ не перекодовує й не проксіює все відео через цей backend. Lampac або багато користувачів потребують окремого вимірювання ресурсів.

## Розгортання після замовлення

Потрібні Linux VPS із Docker Compose і домен/піддомен, DNS якого вказує на сервер. Команди виконуються в копії цього репозиторію на VPS:

```bash
cp server/.env.example server/.env
# У server/.env задайте XOT_API_HOST і новий XOT_SERVER_TOKEN.
# Випадковий токен можна створити командою:
openssl rand -hex 32

docker compose --env-file server/.env -f server/compose.yaml up -d --build
```

Caddy отримує HTTPS-сертифікат для `XOT_API_HOST`. Потрібні відкриті TCP 80/443; процес Node доступний тільки всередині Compose-мережі. Ключ `XOT_SERVER_TOKEN` не повинен потрапити до Git або журналів.

У Cloudflare Worker:

1. Додайте `XOT_BACKEND_URL=https://ваш-api-домен` як змінну.
2. Створіть Secret `XOT_BACKEND_TOKEN` із тим самим випадковим токеном.
3. Опублікуйте Worker та перевірте пошук і відтворення кожного джерела.

Без цих змінних адаптери виконуються безпосередньо у Worker. Для повернення до цього режиму видаліть `XOT_BACKEND_URL` і повторіть деплой. Адреса `m.js` не змінюється.

## Що цей сервер не додає автоматично

- Не встановлює Online MOD, Lumio або Lampac.
- Не створює акаунти Filmix/Rezka та не підвищує їхній тариф.
- Не робить всі джерела з чужого меню доступними.

Додаткові балансери додаються окремо після перевірки API та потоків. Для власного Lampac знадобиться окреме встановлення та адаптер його протоколу.
