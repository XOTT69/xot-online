# 0.3.19 · спрощення та перевірка джерел

Усі вісім пунктів опрацьовано. Дата перевірки: 8 листопада 2026.

1. **Короткий Фільтр.** Український автовибір, повтор пошуку, за потреби
   інший збіг/сезон і «Налаштування ХОТ». Балансери, улюблені студії,
   комфорт, позначки, відстеження, діагностика та Filmix зібрані в налаштуваннях.
2. **Балансери для картки.** Знайдені джерела першими, кількість варіантів
   або озвучень; збережений поточний вибір доступний навіть при помилці.
   Решта — через «Показати всі джерела». Filmix без прив’язаного пристрою
   відкривається через налаштування акаунта. Лінивий опис не називається
   підтвердженим HD: у рядку лишається «Перевірка» до отримання потоку.
3. **Змінити джерело у плеєрі.** Штатна кнопка з SVG, явний вибір джерела
   й студії, позиція та точна серія збережені. Та сама студія сортується першою,
   але не підмінюється автоматично. Ручне перемикання не штрафує справний
   CDN і не погіршує його статистику. Є негайне скасування пошуку; пізні
   результати не відкривають меню. Скасування зберігає паузу. Збір альтернатив
   обмежений 12 секундами; холодна Rezka може потребувати звичайного відкриття
   балансера, де лишається час на пробудження.
4. **Одна кнопка Дивитися.** Для нового фільму з уже відомим HD, за ручним
   вибором/улюбленими студіями/українською перевагою. Джерело, студія й обрана
   якість написані до запуску. Ліниві й SD-описи її не створюють. Продовження
   перегляду має пріоритет; автоматичного запуску немає.
5. **Правдиві назви.** Візуальні назви без рекламованих 4K/HDR/1080p+;
   сирі назви та ID збережених улюблених не змінені. «До 1080p» — максимум
   конкретного набору потоків, верхня кнопка — бажана якість. Мінімум 720p
   зберігається у виборі, резерві та черзі.
6. **Навігація.** У справжній Lampa перевірено Enter, стрілку вниз і Escape
   для нового меню та повернення до результатів. Користувач підтвердив на
   VIDAA стрілки/OK/Назад, звук, перемотування та наступну серію. Нові елементи
   перевірені у Chromium; фізичний VIDAA агентом повторно не тестувався.
7. **Тихе підключення.** Підказка про холодний запуск лише у поточному
   завантаженні Rezka, без модального вікна. У налаштуваннях є явна перевірка
   відповіді сервера: один GET /healthz, до 8 сек, без API-ключа. Відповідь
   сервера не оголошується перевіркою відео. Фонових перевірок/keepalive немає.
8. **Незалежний хост.** Досліджено Collaps, який Kinostrain сам публікує
   поряд із Tortuga. Новий адаптер не ввімкнено: див. результат нижче.

## Живі перевірки на production 0.3.18 перед оновленням

Це реальний запуск у Lampa/Chromium через публічний Worker і CDN, не лише
пошукова видача. Адреси відео й ключі у звіт не включені.

| Джерело | Фільм | Серіал / результат |
| --- | --- | --- |
| Kinostrain | «Топ Ґан: Меверік», 1280×675, перемотування до 60 с | «Ззовні» 1×1 → 1×2, 1280×640 |
| Eneyida | «Оселя зла: Вітаємо у Раккун-Сіті», 1280×530 і 1920×795 | «Король Талси» 2×1, правильний сезон/епізод |
| KinoVezha | Та сама «Оселя зла», 1280×530 і 1920×795 | «Пуститися берега» 2×1, 720p; лише обраний епізод |
| UASerials | Та сама «Оселя зла», 1280×530 і 1920×795 | «Король Талси» 2×1 |
| UFDub | «Небесні створіння», 1920×1080, метадані до запуску, перемотування | Неаніме-фільм; перевірка не доводить наявності будь-якої назви в каталозі |
| Serialno | Джерело лише для серіалів | «Ззовні» 1×1 → 1×2, 1920×960 |

Обрізані чорні смуги пояснюють висоту менше 720/1080 при стандартній ширині
1280/1920. Тест KinoVezha виправлено для єдиної якості: Lampa може прибрати
поле `quality`, залишивши один потік; це була помилка звіту, не адаптера.
Filmix без відповідного доступу повертає SD, яке ХОТ приховує. Акаунт Filmix
користувача не використовувався. Rezka за проханням користувача повторно не
аудитувалася: її backend, секрет, relay та `wrangler.toml` не змінені.

## Дослідження Collaps

Публічна сторінка [«Меверіка» у Kinostrain](https://kinostrain.com/movie-top-gan-meverik)
містить посилання на `api.nextembed.ws`; «Ззовні» має опубліковані номери
серій. З ноутбука звичайні GET отримали 200, HLS 1280×720, окремі аудіодоріжки
та українські студії Postmodern / DniproFilm. JavaScript сторінки не виконувався.
Зіставлення студій уточнено за `player-venom@0.3.8`: `names` відповідає
початковому порядку аудіо, `order` — порядку меню. У DniproFilm мовний тег
плейлиста помилково `ru`, тому визначати студію лише за LANGUAGE не можна.

Із тимчасового Cloudflare Worker **сам embed повернув HTTP 422** ще до HLS.
Причину 422 джерело не пояснило; це не доведений геоблок чи потреба в акаунті.
Наскрізна спроба Lampa → Worker не запустила відео. Виробничий список тому
не розширювався; експериментальний код не входить у плагін. Тимчасовий Worker
`xot-collaps-qa` після діагностики видалений. Ключ Rezka туди не переносився.
Оренда, платні проксі та аніме не додавалися.

## Перевірки 0.3.19

- `npm test`: 217 успішних перевірок.
- `smoke:sources`: короткий і повний список джерел, кількості, один Дивитися,
  без автозапуску, кеш/свіжі post, вимкнення всього та відновлення, клавіатурне
  повернення, ручний статус без фонових запитів.
- `smoke:comfort`: профілі, сезони, метадані, тихі оновлення, субтитри,
  заставка, ізоляція профілів і скасування пізніх результатів.
- `smoke:favorite-voices`: старі сирі назви улюблених, ручний вибір,
  пріоритети, усі озвучення, повернення в автоматичний режим.
- `smoke:watch-controls`: позначки, undo, одна основна дія, наступна серія,
  пропуски й недоступні серії, захист від зміни профілю.
- `smoke:backup`: справжнє HD-відео Eneyida, контрольований каталог
  альтернативного джерела з тим самим інвентарем та реальним розкриттям HLS;
  пауза й скасування під час пошуку, збереження часу, та сама студія,
  наступна серія, без штрафу справному джерелу. Інжекція фатальної помилки:
  SD й спільний несправний CDN не пропонуються; закриття прибирає меню.

Перевірка механізму перемикання не підміняє окремий живий аудит каталогів.
Зовнішні сайти можуть змінюватися; успіх наведених назв не гарантує весь каталог.

## Публікація

Опубліковано 0.3.19 за тим самим URL `m.js`; фінальна версія Worker:
`de644702-cc60-48e1-9afe-5a356b5446c8`. Assets синхронізовані, CORS `*`,
`cache-control: no-store`. `--keep-vars` зберіг наявні налаштування та секрети.

Після публікації без підміни assets успішно повторені `smoke:hd`
(«Меверік», перемотування, «Ззовні» 1×1 → 1×2), `smoke:eneyida`
(720p/1080p та «Король Талси» 2×1) і `smoke:backup`
(позиція 65 с, 1280×640, наступна серія, скасування, відхилення SD/CDN).
У цих сценаріях не було помилок JavaScript.
