# 0.3.17 · HD та нове джерело, 8 листопада 2026

## Мінімум 720p

Список, резервний пошук, продовження й черга не запускають 360/480p. Відсутність
720p не означає вибір SD: показується порожній стан. Стара глобальна перевага
480p лишається в Storage для інших плагінів, але ХОТ читає її як 720p. Меню
пропонує тільки 720/1080/1440/2160. Назва озвучення з «4K» не доводить якості.

Для невідомого MP4 окремий video з `preload=metadata`, без autoplay і crossOrigin,
перевіряє videoWidth/videoHeight. Після результату, помилки чи скасування src
видаляється. 12 секунд на перевірку; невідоме/SD відхиляється. Підтверджені
розміри лишаються в пам’яті поточної картки, а не довгостроковому кеші URL.

Адаптивний HLS з окремим аудіо/субтитрами використовує `/api/hd.m3u8`:
обмежений список HTTPS CDN, максимум два перенаправлення, до 128 KiB master,
без cookie й авторизації. SD й варіанти невідомої роздільності вилучені,
audio/subtitle URI збережені абсолютними. Декодоване SD, якщо інший сервіс
неправильно підписав якість або плеєр змінив потік, також зупиняється у ХОТ. Відеофрагменти цей маршрут не передає.
Звичайні HD-плейлисти йдуть напряму. Обрізане кіношне співвідношення сторін
визначається шириною: 1280×675/640 — відповідні 720p-представлення з джерела;
ніякого масштабування чи підміни етикетки за назвою фільму немає.

Верхні кнопки: балансер, якість, озвучення, фільтр. Назва балансера читається
повністю, відступи компактні, штатна горизонтальна навігація Lampa збережена.
Якість у рядку — маленька нейтральна позначка; попередній перегляд невідомого
потоку пояснює «Перевірка HD перед запуском». Прогрес і продовження збережені.

## Kinostrain

Відкритий каталог `https://kinostrain.com`, JSON-пошук
`https://api.kinostrain.com/api/search?q=…&limit=20`. Картки містять повні
локалізовану/оригінальну назви, рік і тип. Nuxt `__NUXT_DATA__` читається як
індексований JSON із межами глибини/кількості вузлів; скрипти не виконуються.
Для CPU Worker не розгортаються актори, коментарі й рекомендації.

У цій версії читається тільки опублікований Tortuga-плеєр; Ashdi, Vidsrc й
Collaps не видаються за реалізовані адаптери. Для серіалу відкриваються дані
до п’яти сезонів, без запитів кожного відеоплейлиста. Вибраний епізод повторно
звіряється з даними його сезону, студією та URL плеєра. Власне ім’я студії не
перетворюється автоматично на ознаку української мови. Аніме виключене.

З Cloudflare та ноутбука підтверджено 200/HLS та 206/MPEG-TS. У справжній
Lampa/Chromium:

| Перевірка | Результат |
| --- | --- |
| «Топ Ґан: Меверік», Postmodern | 1280×675, 7814,5 с; запуск і перемотування до 60 с. |
| «Ззовні» 1×1, HDrezka Studio | 1280×640, 3155,3 с. |
| Штатний Next → 1×2 | 1280×640, 2966,9 с; озвучення збережене. |
| Якості, передані плеєру | Тільки 1080p/720p, без 480p. |
| UFDub, «Небесні створіння» | Метадані перед запуском: 1920×1080; 6535,3 с, перемотування до 60 с. |

Частина відео спільна з іншими каталогами. Це розширення пошуку, а не обіцянка
окремого CDN. UAKino CX перевірений звичайним запитом: 403/Cloudflare challenge;
його адаптер не додано. [Первинний відкритий адаптер Kinostrain](https://github.com/CakesTwix/cloudstream-extensions-uk/tree/master/KinostrainProvider)
використаний для дослідження формату, а не як доказ доступності з Worker.

## Перевірки

`npm test`: 211 перевірок, включно з відмовою SD/невідомому HLS, реальними
метаданими MP4 у контрольованому тесті, скасуванням, збереженням аудіо/субтитрів,
SSRF/redirect bounds, точним збігом нового каталогу та приватним relay.
`npm run smoke:hd`: справжня Lampa, контрольований SD-only Filmix, верхнє меню
без 480p, збережена стара глобальна перевага, далі реальне HD-відео Kinostrain.
`npm run smoke:ufdub-hd`: реальний неаніме-фільм, перевірка MP4 і перемотування.
Після публікації 0.3.17 `smoke:hd` повторно пройшов саме з production `m.js`,
без підміни локальними assets: HD-фільм, перемотування, серії 1×1 → 1×2.
Сценарії `smoke:source-controls` та `smoke:features` також пройшли з оновленими
правилами якості. Тимчасовий QA Worker прибрано після перевірок.
Chromium не доводить сумісність кожного декодера VIDAA: телевізор перевіряється
користувачем після оновлення за незмінним посиланням `m.js`.

## Rezka

Прямі запити з Cloudflare 08.11 знову повернули `rezka_access_denied`. Сервер
користувача Render отримує плейлисти з альтернативного origin; прямі CDN-URL
раніше повертали 404 на пристрої при 200/206 із Render.

Підготовлено HLS relay на вже наявному Render. Приватний API може повернути
підписані адреси `/media/…/index.m3u8`: HMAC, до 6 годин, дозволені CDN, без
передавання API-ключа чи source-cookie на CDN. Маніфести переписуються, фрагменти
стримляться зі скасуванням і межами, Range зберігається. Без підпису/після
закінчення строку — 403. Це додатковий відеотрафік Render, не «безкоштовний
необмежений CDN». Тариф Free не змінювався.

08.11 пристрій через новий relay отримав справжній маніфест (200) і перший
кілобайт MPEG-TS (206). Після перевірки H.264 SPS виявлено: назви якостей джерела не збігаються з
фактичними розмірами. Рекламоване 720p має 854×480, рекламоване 1080p —
1280×720. Сервер перевіряє перші 64 KiB одного опублікованого TS-фрагмента,
відкидає SD і перейменовує варіант за фактичними розмірами. H.264 SPS читається
обмеженим JS-парсером без ffmpeg; невідомий/зашифрований формат не оголошується HD.

У справжній Lampa/Chromium перевірено через приватний API Render:

| Перевірка Rezka | Фактичний результат |
| --- | --- |
| «Меверік», український дубляж | 1280×720, 7814,0 с, запуск і перемотування до 60 с. |
| «Король Талси», українська 1+1, 1×1 | 1280×640, 2379,1 с. |
| Штатний Next → 1×2 | 1280×640, 2127,3 с; та сама студія. |
| Передані якості | Тільки перевірені 720p. |

Звичайний акаунт користувача не використовувався; це гостьова перевірка.
На Render увімкнено `XOT_REZKA_RELAY=1`; розгортання запускається на commit,
а збірка сама виконує тести. Production Worker ще не підключений до Render:
для передачі серверного ключа потрібний явний дозвіл користувача. Перевірка
Chromium не доводить роботу конкретного декодера VIDAA.

Тестовий приватний API викликається лише з Node на пристрої до Render. Ключ
не передавався Cloudflare, не вбудовувався у плагін, не записувався у Git.
Попередня відмова автоматичного схвалення перенесення ключа лишається чинною:
для такого запису в Cloudflare потрібний явний дозвіл користувача.
