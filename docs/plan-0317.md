# План 0.3.17 · 8 листопада 2026

1. Мінімум 720p: фільтрація списку, резерва, черги та запуску; старе бажане
   480p не впливає на інші плагіни й у ХОТ читається як 720p.
2. Фактична якість: назва озвучення не доводить 4K; невідомий MP4 перевіряється
   за відеометаданими до запуску, HLS без підтвердженої роздільності відхиляється.
3. HLS з окремим аудіо: залишити аудіо/субтитри, вилучити SD-варіанти з master,
   не передавати відеофрагменти через Worker.
4. Верхні кнопки озвучення й бажаної якості; стримані позначки та порожній стан
   «Немає відео від 720p» замість запуску SD чи списку несправних джерел.
5. Перевірити нові каталоги Kinostrain та UAKino CX: точний збіг, плеєр,
   роздільність, доступність CDN з Worker і пристрою. Лише підтверджене в меню.
6. Rezka: повторна перевірка гостьової сесії, origin і прив’язки медіа до IP;
   не оголошувати отримане посилання доказом відтворення. Врахувати попередню
   заборону передачі ключа Render у Cloudflare без явного дозволу.
7. Тести межі 720p, реальна Lampa/Chromium для фільму, серіалу, резерва,
   озвучення та навігації; опублікувати лише перевірений результат.

Обмеження користувача: без оренди, без постійно ввімкненого ноутбука,
Hisense VIDAA та браузер, аніме не додавати. Нові платні сервіси не активувати.

Стан: 0.3.17 опубліковано, пункти 1–5 та браузерна перевірка 7 виконані.
Rezka пройшла фактичні 720p, перемотування та наступну серію через Render Free;
приватний API готовий. Для постійного Worker → Render підключення запитано
окремий дозвіл перенести API-ключ у Cloudflare Secret. До відповіді маршрут
production вимкнений. Перевірка конкретного VIDAA залишається на телевізорі.
