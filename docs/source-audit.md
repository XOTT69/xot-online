# Джерела з Lumio: перевірка 26 жовтня 2026

Джерело для аналізу: https://beta.mitsu.tv/plugins/lumio.js. Це референс протоколів і списку джерел, а не залежність ХОТ. Файл Lumio не включений у репозиторій і не виконується плагіном.

У його реєстрі зазначені Zetflix, VeoVeo, CDNVideoHub, Kinotochka, Phantom, UAFilm, LeProduction, Filmix, VKMovie та джерело оригіналу із субтитрами. Окремі діагностичні маршрути містять Cinemar, HDRezka, Gidonline, HDVB і Collaps. Наявність у цьому реєстрі не перевіряє поточну доступність кожного джерела.

Основний список завантажується через `/api/lite/events` на сервері Mitsu/Lampac. Частина потоків використовує VIP device/token, lease або окремий device transport. Це серверна реалізація, яку не можна відтворити простим копіюванням назв у меню.

| Компонент | Що підтверджено | Стан у ХОТ |
| --- | --- | --- |
| Filmix | Прямі анонімні API search/post, пряме HTTPS-відео | Незалежний адаптер; перевірено реальне відтворення |
| AniLibria | Офіційний публічний API повертає пошук, релізи та HTTPS HLS-потоки | Додано окремий адаптер без VPS і ключа; це додаткове аніме-джерело, не сервер Mitsu |
| HDRezka | Прямий пошук із Worker; сторінка фільму вимагає антибот-перевірку | Незалежний парсер і AJAX-адаптер, поточне обмеження показується користувачу |
| `lv.hdrezka.inc` | Публічний каталог із іншим форматом `postItem` і плеєрами HDVB/Cinemar | Це окремий каталог; його не видаємо за класичний HDRezka AJAX API |
| `gidonline.now` | Публічний каталог доступний | Потоковий адаптер не реалізовано й не позначено робочим |
| Інші серверні джерела Lumio | У клієнті є назви та маршрути Mitsu | Потребують окремої реалізації/доступного API й живої перевірки |

Власний VPS може бути місцем для додаткових серверних адаптерів або власного Lampac. Підготовлений Node backend ХОТ не є встановленим Lampac і поки містить тільки власні Filmix/Rezka та вже наявну інфраструктуру API.

Поточне рішення користувача: без оренди сервера, використовуємо наявний Cloudflare Worker. Підготовлений VPS backend залишається невикористаним.
